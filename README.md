# 健康档案库

匿名个人健康档案，按编号管理（HR-001、HR-002……），任何大模型拿到链接都能阅读和解读。

## 档案结构

每份档案对应两个文件，位于 `records/`：

| 层 | 文件 | 内容 | 谁能改 | 怎么改 |
|---|---|---|---|---|
| 事实层 | `HR-xxx-facts.md` | 基本信息、用药、病史、化验、就诊 | 仅维护人 | 新数据就添加；改错在“更正记录”登记原值；每次修改都更新表头的“事实版本”日期 |
| 评论层 | `HR-xxx-comments.md` | 各模型、医生、本人的解读 | 所有协作者 | 只能添加；不修改、不删除别人的评论 |

总目录见 [INDEX.md](INDEX.md)。

## 让任何模型读档案

把下面这段复制给 ChatGPT、Claude、Gemini 等能打开网页的模型（以 HR-001 为例）：

```
请阅读这份健康档案，按档案开头“给 AI 模型”的说明来解读，然后回答我的问题。
事实层：https://raw.githubusercontent.com/washingtonshao-web/health-records/main/records/HR-001-facts.md
评论层：https://raw.githubusercontent.com/washingtonshao-web/health-records/main/records/HR-001-comments.md
我的问题：……
```

模型打不开链接时，在 GitHub 上打开文件，点 Raw，把全文复制粘贴给它。

## 把模型的解读存回评论层

1. 模型回答完，会按格式输出一个**评论块**（以 `### C-????` 开头）。
2. 把评论块复制，粘贴到这份档案的评论 Issue 里（HR-001 → [Issue #1](https://github.com/washingtonshao-web/health-records/issues/1)），提交。
3. 约 30 秒后，机器人自动给评论编号，把它追加到评论层最上面，并在 Issue 里回复“已追加为 C-00xx”。

手机网页上也能完成这几步。只有仓库所有者和协作者提交的评论会被采纳。

## 更新事实

- 拿到新报告时，把报告交给模型，让它输出“事实更新提议”。
- 维护人对照原始报告核对后，在 GitHub 网页上编辑 facts 文件写入，或者交给 Claude Code / Codex 直接修改并提交。
- 事实更新提议贴到 Issue 里不会自动写入事实层，机器人只会回复提醒维护人核对。这是有意的：模型识别错的数字不能自动变成“事实”。

## 定期整理

评论较多时，让一个模型通读评论层，重写顶部的“综合意见”（共识 / 分歧 / 待办），并更新“最后整理”日期。

## 新建档案

1. 在 Issues 新建一个，标题为 `HR-002 评论`。
2. 运行 `python scripts/new_record.py HR-002 <该 Issue 链接>`。
3. 在 INDEX.md 加一行，提交。

编号永不复用；停用的档案在 INDEX.md 里标为“停用”。

## 隐私约定

- 档案中不写姓名、病历号、证件号、住址、医院名称；报告照片和 PDF 不放进本仓库。
- 编号与真人的对应关系不放在本仓库，由维护人另行保管。
- 本仓库公开：任何拿到链接的人都能看到全部档案。新建档案前，要先征得本人同意。
