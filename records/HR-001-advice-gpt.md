| 其他吸烟相关癌症 | 中国癌症登记及中国吸烟与多疾病队列 | 按癌种组合估计；戒烟降低部分风险，但不能全部清零 |
| 2 型糖尿病 | 中国队列因筛查方式不同，报告发病率约 **2.8–9.5/千人年** | 目前正常 BMI、HbA1c 下调风险；脂肪肝史、TG/HDL 异常及年龄增长上调；祖母患病不按一级亲属家族史处理 |
| COPD | 中国 ≥40 岁男性患病率约 **19%**；正常肺功能人群长期随访显示，持续吸烟者发生 COPD 的比例可达数十个百分点 | 目前无阻塞，近期风险较低；持续暴露后风险积累。没有把“中国患病率”直接当成个人未来发病率 |
| 肝硬化 | 脂肪肝自然史研究表明，纤维化阶段比单纯脂肪肝或 ALT 更决定结局 | 按目前无进展期纤维化、体重改善估计；不按重度饮酒者计算 |
| 痴呆 | 中国四地区队列中，≥65 岁人群发病率约 **12.1/千人年**，随年龄迅速上升 | 按男性、血管风险及竞争死亡外推；不是把老年平均年发病率从 39 岁开始累加 |

对应来源：[China-PAR](https://pubmed.ncbi.nlm.nih.gov/27682885/)、[中国卒中终生风险队列](https://pubmed.ncbi.nlm.nih.gov/27512963/)、[欧洲肺癌累积风险](https://pubmed.ncbi.nlm.nih.gov/15292933/)、[结直肠癌家族史证据](https://www.ncbi.nlm.nih.gov/sites/books/NBK570913/pdf/Bookshelf_NBK570913.pdf)、[内镜长期结局](https://pubmed.ncbi.nlm.nih.gov/24047059/)、[非肝硬化脂肪肝队列一](https://pubmed.ncbi.nlm.nih.gov/38079023/)、[队列二](https://pubmed.ncbi.nlm.nih.gov/37395730/)、[幽门螺杆菌根除试验汇总](https://pubmed.ncbi.nlm.nih.gov/32628791/)、[GLOBOCAN 中国](https://gco.iarc.who.int/media/globocan/factsheets/populations/160-china-fact-sheet.pdf)、[中国癌症登记研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11256708/)、[中国糖尿病发病研究](https://www.ahajournals.org/doi/10.1161/JAHA.118.011368)、[中国 COPD 调查](https://pubmed.ncbi.nlm.nih.gov/29650407/)、[COPD 长期队列](https://pubmed.ncbi.nlm.nih.gov/17071833/)、[脂肪肝前瞻研究](https://pubmed.ncbi.nlm.nih.gov/34670043/)、[中国痴呆队列](https://pubmed.ncbi.nlm.nih.gov/26086181/)。

几个容易影响解读的细节：

- **肺结节稳定不代表未来不会得肺癌。** 目前这些小实性结节多年稳定，对“它们现在是不是恶性”是好消息；未来肺癌风险主要由今后的暴露决定。
- **胃泌素 44.58 pmol/L 不能直接换算成胃癌概率。** 伏诺拉生本来就可能引起高胃泌素血症。[VISION 长期研究](https://pubmed.ncbi.nlm.nih.gov/39209187/)
- **不能把替尔泊肽的糖尿病预防结果照搬。** 相关试验研究的是肥胖合并糖尿病前期人群，使用的治疗剂量也与他的 2.5 mg 不同；他目前没有糖尿病前期的已知证据。[SURMOUNT-1 延长随访](https://pubmed.ncbi.nlm.nih.gov/39536238/)
- **B 的前列腺癌诊断风险略高，不意味着干预致癌。** 活得更久和诊断更充分都会提高累积诊断概率；死亡风险仍可降低。

**4．收益排序：最值得做什么**

下面的寿命收益均为**对他的外推**，不是试验直接测得的个人获益；各项相互重叠，不能相加。

| 优先级 | 措施 | 对他的最佳量化判断 | 证据与解释 |
|---|---|---|---|
| **1** | **彻底戒烟，包括加热烟** | 单项平均寿命收益约 **4–7 年**；到 79 岁肺癌约 **11%→3.5%**，COPD 约 **28%→11%** | 中国吸烟队列及戒烟研究最有力；纯卷烟长期持续者的戒烟收益可能更大 |
| **2** | **降低终生 LDL/ApoB 暴露，并随年龄管理血压** | 降脂单项约 **0.5–1.5 年**；若 LDL 降低约 1 mmol/L，重大血管事件相对风险降低约 **20%–25%** | CTT 随机试验汇总支持每降低 1 mmol/L LDL，重大血管事件 RR 约 **0.79**；几十年寿命收益为外推 |
| **3** | **维持已取得的减重成果，增加抗阻训练和规律活动** | 相比体重反弹并长期活动不足，约 **0.5–2 年**；对糖尿病、脂肪肝、体能和失能风险都有收益 | 他已经正常体重并爬山，增量收益小于从完全不运动、明显肥胖开始的人 |
| **4** | **把结肠息肉管理做完整** | 到 79 岁结直肠癌约 **6%→3%**；平均寿命收益约 **0.2–0.6 年** | 息肉切除和内镜监测可预防癌症；NPS 研究观察到结直肠癌死亡降低约 **53%**，但不能把完整效应重复加到已接受内镜者身上 |
| **5** | **查清铁蛋白升高、肝纤维化及病毒性肝炎状态** | 当前中心情景中的平均寿命收益可能不足 **0.5 年**；若查出可治疗的铁过载、活动性肝炎或显著纤维化，价值会大幅上升 | 这是能改变风险分层的检查，不能在检查前给确定的延寿数字 |
| **6** | **改善睡眠时长与规律性，避免集中饮酒** | 延寿粗估 **0–1 年**，证据把握低；对白天状态、情绪、食欲调节和工作效率更有直接价值 | 睡眠证据主要是观察性关联，不能把“晚睡”机械折算成少活几年 |
| **7** | **按实际风险进行肺癌、胃癌等筛查** | 对他在既有体检基础上的额外寿命收益，多半是**数月量级** | LDCT 试验可使合适高危人群肺癌死亡相对降低约 **20%–24%**；筛查不会消除吸烟造成的新发癌症 |
| **低优先级** | 增加补充剂、泛肿瘤标志物、无指征全身扫描、未验证抗衰治疗 | **没有可靠证据能为他增加可量化的寿命** | 金钱充足应提高有效干预的持续性和诊疗质量 |

证据：[CTT 降脂试验汇总](https://pubmed.ncbi.nlm.nih.gov/22607822/)、[运动与寿命队列](https://pubmed.ncbi.nlm.nih.gov/23139642/)、[息肉切除与死亡](https://pubmed.ncbi.nlm.nih.gov/22356322/)、[亚洲睡眠队列](https://pubmed.ncbi.nlm.nih.gov/34477853/)、[NELSON 肺癌筛查试验](https://www.nejm.org/doi/10.1056/NEJMoa1911793)。

如果用“无重大心血管病、癌症和慢性呼吸系统病的生活年数”衡量，我估计 B 比 A 可增加约 **4–7 年**。中国队列中，健康生活方式组男性的对应无病预期寿命高约 **6.3 年**，可作为量级参照，但不是他的直接结果。[中国健康寿命研究](https://pubmed.ncbi.nlm.nih.gov/37430072/)

对他而言，具体执行重点是：

1. **把戒烟当作治疗项目。** 戒烟门诊、行为支持，配合伐尼克兰或合适的尼古丁替代治疗，都比继续换烟草产品更有证据。药用尼古丁替代不等于继续使用加热烟。[WHO 戒烟指南](https://www.who.int/news/item/02-07-2024-who-releases-first-ever-clinical-treatment-guideline-for-tobacco-cessation-in-adults)

2. **先复查减重后的血脂，再决定降脂强度。** 他不是仅凭 LDL 3.40 就自动进入极高危人群。我的倾向是积极讨论长期降脂，尤其当 ApoB、非 HDL 胆固醇仍偏高时；但 **LDL <1.8 mmol/L 并不是他目前已被指南强制要求的目标**。[中国血脂管理指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC10498001/)

3. **核实息肉是否切除及其病理。** 这是筛查方面最重要的缺口。低风险小腺瘤与进展期腺瘤的复查间隔明显不同，有家族史也应纳入决定，不能简单规定所有人每年做肠镜。[息肉切除后随访指南](https://gastro.org/clinical-guidance/follow-up-after-colonoscopy-and-polypectomy-a-consensus-update-by-the-u-s-multi-society-task-force-on-colorectal-cancer/)

4. **近期复查铁蛋白、转铁蛋白饱和度、肝功能，并评估肝脏弹性。** 按 2025 年数据算得 FIB-4 约 **0.54**，低于常用低风险界值 **1.3**，是好消息，但不能解释铁蛋白升高。无明确缺铁指征时，不应继续自行补铁；而且他的铁蛋白升高早于补铁，不能把问题全归咎于补充剂。[AASLD 指南](https://pubmed.ncbi.nlm.nih.gov/?term=36727674)、[高铁蛋白评估指南](https://www2.gov.bc.ca/assets/gov/health/practitioner-pro/bc-guidelines/high_ferritin_and_iron_overload_guideline.pdf)

5. **纠正药物对筛查的干扰。** 抑酸药可能让幽门螺杆菌呼气试验假阴性；需要复核时，由医生安排停药窗口。非那雄胺 1 mg 也可能使 PSA 降低约 **40%–50%**，解读 PSA 时必须注明用药。[幽门螺杆菌指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC13283202/)、[非那雄胺 1 mg 随机试验](https://pubmed.ncbi.nlm.nih.gov/17196507/)

目前的肺结节随访可以由呼吸科结合既往影像安排，但应与人群筛查区分。中国 2024 年肺癌筛查方案一般针对 **50–74 岁**高风险者，吸烟标准之一为 **≥20 包年**。加热烟暴露不能直接按已有验证的卷烟包年折算；他目前也不能仅因外祖父肺癌就算作“一级亲属肺癌史”。[国家卫健委筛查方案](https://www.nhc.gov.cn/ylyjs/gzdt/202408/42f43b5f0c4c4ebe90c78ee127959b92.shtml)

**对结论影响最大的假设**

| 假设或未知信息 | 对结果可能造成的影响 |
|---|---|
| **加热烟实际长期危害、以后是否恢复卷烟** | 最大的不确定性。若长期只用加热烟且真实危害显著低于中心假设，A 的寿命中位数可能上移约 **2–4 年**；若恢复长期每日一包卷烟，可能下移约 **1–3 年**。均为敏感性外推 |
| **戒烟能否持续几十年** | B 假设持久戒烟；短暂停用后复吸不能得到表中的完整收益 |
| **未来医疗进步与优质医疗的实际收益** | 没有“无限金钱增加固定几年寿命”的已验证系数。它是 B 能达到接近高寿命城市人群水平的依据之一，也是绝对寿命误差的主要来源 |
| **2026 年减重后的真实血脂、腰围、肝脂肪和炎症** | 若已明显改善，A/B 风险都会下降，额外降脂与体重管理的增量收益也会缩小 |
| **息肉病理、数量、大小和切除状态** | 可能让结直肠癌预测出现数倍差异；当前表假定没有未处理的进展期病变或遗传性癌症综合征 |
| **铁过载、肝纤维化、乙肝/丙肝的真实状态** | 肝癌及肝硬化预测最依赖这些。当前假设没有活动性慢性病毒性肝炎或进展期纤维化 |
| **幽门螺杆菌与胃黏膜病理** | 若存在持续感染、广泛萎缩或肠化生，胃癌风险应上调；不能靠抑酸期间的阴性呼气结果完全排除 |
| **未来血压、体重反弹及糖尿病发生** | 尤其影响几十年后的卒中、心脏病、肾病和痴呆；没有假定他终身保持现在的血压 |
| **空气污染、职业暴露及未记录的遗传风险** | 会改变肺癌、COPD 和心血管风险；目前按普通中国城市暴露、无特殊职业暴露估计 |

自查结论：表内死亡分项与总风险已核对，寿命均值和区间与生存曲线一致。**最需要保留的限制是：长达 40–50 年的个人分病种数字属于文献约束下的判断性预测，不能被理解为经过验证的精确概率。** 本次未进行独立 Opus 复核。最值得优先落实的判断仍是：**彻底戒烟，其次管理终生血脂暴露，并查清息肉病理和铁蛋白异常。**
